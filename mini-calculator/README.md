# JavaScript Calculator

This is a simple calculator written in pure JavaScript that performs basic arithmetic operations: addition, subtraction, multiplication, and division.

## 📋 Description

The user enters two numbers and selects one of the operations: `+`, `-`, `*`, or `/`. The calculation result is displayed in the console. If the input is not a number or the operation is invalid, an error message is shown.

## 🚀 How to Run

1. Copy the code into a file named `index.js`.
2. Open an HTML file with the script connected, or run the script in the browser console.
3. Enter the numbers and operation when the `prompt` windows appear.

## 🧪 Examples

```js
calculator(10, 5, "+"); // 15
calculator(7, 2, "-");  // 5
calculator(3, 3, "*");  // 9
calculator(10, 2, "/"); // 5
